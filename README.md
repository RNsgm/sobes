# speedtest

Консольный скрипт на Python, который измеряет скорость скачивания ресурса по HTTP(S).

Скрипт делает 10 последовательных запросов к ресурсу и на каждом ждёт, пока тело ответа придёт полностью. Для каждого запроса он записывает время и объём скачанных данных, затем выводит:

- скорость каждого запроса;
- общую скорость, посчитанную по среднему времени запроса и объёму всех скачанных данных.

**Единица измерения скорости — Мбит/с** (мегабиты в секунду, 1 Мбит = 1 000 000 бит).

## Требования

- Python 3.9+
- [requests](https://pypi.org/project/requests/)

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | адрес ресурса (обязательный) |
| `-n`, `--count` | `10` | количество последовательных запросов |
| `-t`, `--timeout` | `30` | таймаут соединения и чтения, секунды |
| `-more`, `--more` | выключен | подробный вывод: таблица по каждому запросу и итоги |

## Вывод

### Без `-more` (по умолчанию)

Выводится одно число: общая скорость в Мбит/с, с двумя знаками после точки. Такой вывод удобно использовать в других скриптах.

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

```
10.17
```

Сообщения об ошибках запросов пишутся в stderr, поэтому в stdout всегда остаётся только число.

### С `-more`

Для каждого запроса выводятся время, объём и скорость, а в конце — итоги.

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat -more
```

```
Ресурс: https://example.com/file.bin
  #    Время, с     Объём, байт   Скорость, Мбит/с
  1       0.842         1048576               9.96
  ...
 10       0.811         1048576              10.34

Успешных запросов: 10 из 10
Всего скачано:     10485760 байт
Среднее время:     0.825 с
Общая скорость:    10.17 Мбит/с
```

## Как считается

- **Время запроса** — от отправки запроса до получения последнего байта тела ответа (`time.perf_counter`).
- **Объём** — байты тела ответа, фактически переданные по сети (до распаковки gzip, если сервер сжал ответ).
- **Скорость запроса** = `объём × 8 / время / 10^6`, Мбит/с.
- **Общая скорость** = `(объём всех данных / число запросов) × 8 / среднее время / 10^6`, Мбит/с. Это то же самое, что весь объём, делённый на суммарное время.

Если запрос завершился ошибкой, он не учитывается в общей скорости. Код возврата: `0` — все запросы успешны, `2` — часть запросов с ошибкой, `1` — ни одного успешного.
